# Как засунуть это в твой Bitrix24 (для собеса)

Bitrix облако открывает приложение по **публичному HTTPS-URL**.  
Локальный `localhost` портал сам не увидит — нужен туннель (ngrok) или хостинг.

## 1. Запусти демо

```powershell
cd C:\1223\bitrix-crm-demo
npm run dev -- --host 127.0.0.1 --port 5173
```

## 2. Открой туннель на этот порт

Установи [ngrok](https://ngrok.com/), затем:

```powershell
ngrok http 5173
```

Скопируй HTTPS-ссылку вида `https://xxxx.ngrok-free.app`

## 3. Создай локальное приложение в Bitrix24

1. Bitrix24 → **Разработчикам** → **Другое** → **Локальное приложение**
2. Название: `CRM Vue Demo`
3. Тип: **Серверное** / с интерфейсом
4. **Путь вашего обработчика**: `https://xxxx.ngrok-free.app/`
5. **Путь для первоначальной установки**: тот же URL
6. Отметь пункты меню / встройки:
   - Пункт главного меню: `CRM Vue Demo`
   - Встройка в карточку сделки: `CRM_DEAL_DETAIL_TAB` (вкладка в сделке)
7. Права: **CRM** (сделки, контакты)
8. Сохрани и установи приложение

## 4. Что должно появиться в портале

- Пункт меню с твоим Vue-приложением
- В карточке **сделки** — вкладка с виджетом (откроется сразу на этой сделке)
- Режим в шапке: **«живой Bitrix24 CRM»**

## 5. Данные для демо на собесе

Перед собесом заведи в CRM 3–5 сделок с понятными названиями:
- Подключение FTTH
- Смена тарифа
- Монтаж

И покажи:
1. список сделок из живого CRM  
2. карточку сделки / вкладку  
3. портал монтажника  
4. карту покрытия  

## Важно

- Пока ngrok выключен — в Битриксе приложение не откроется  
- Для постоянного демо лучше залить `npm run build` на Vercel/Netlify и указать этот URL в приложении  
- На собесе честно говори: портал монтажника и карта — UI-демо; сделки тянутся из CRM через `BX24`
